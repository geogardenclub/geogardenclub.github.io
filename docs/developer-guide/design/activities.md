### Activity types

There are many different activities that we want to show the gardeners. They can be grouped into N categories:
* Badge achievement activities for gardens, gardeners, and chapters (not yet implemented).
* Added activities for chapters, gardens, observations, crops, varieties, users/gardeners, planting outcomes.
* Planting activities: start, start indoors, start outdoors, transplant, havest start, harvest end, pull.
* Miscellaneous activities: forum topic, other.
