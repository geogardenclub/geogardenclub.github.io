# Missing Prices

<img width="300" src="/img/admin-guide/feature-management/prices/missing_prices.png"/>

The Missing Prices page shows the crops with plantings with outcomes that have a quantity, but no price. You can [create a new price](create_missing.md) for any of these crops by clicking on the crop name.
